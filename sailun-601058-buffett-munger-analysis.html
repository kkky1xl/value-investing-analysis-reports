Prompt 1: 业务本质与行业定性

执行级别：快速筛查级

业务本质

巴菲特：

赛轮轮胎是中国轮胎行业全球化布局的标杆企业。核心模式：在国内建设生产基地 → 在海外低成本/免税地区复制产能 → 利用当地关税优势向全球市场供货。

  • 国内基地（4个）：青岛、东营、沈阳、潍坊
  • 海外基地（5个）：越南（满产）、柬埔寨（满产）、印尼（产能爬坡中）、墨西哥（2025年6月投产）、埃及（在建）
  • 产品线：半钢子午线轮胎（乘用车）、全钢子午线轮胎（商用车）、非公路轮胎（OTR）
  • 规划总产能：3,600万条半钢 + 330万条全钢 + 2万吨非公路轮胎
  • 海外资产占比：62.88% — 中国轮胎企业中最高
芒格：

这个生意的本质是"把中国的制造能力搬到海外关税洼地"。美国对华轮胎综合关税已超100%，直接出口已不可能。赛轮通过越南、柬埔寨、墨西哥等基地绕开关税壁垒，这是生存策略而非单纯的竞争优势。海外基地净利率17.7%（越南），远高于国内，说明关税套利是利润核心来源。但这也意味着：一旦贸易规则再次改变（如美国对越南也加征关税），利润基础将被动摇。

芒格：

轮胎行业是一个"三高一低"的行业——高度周期性（原材料+汽车周期）、高资本密集（建厂投资大）、高贸易壁垒（关税/反倾销频繁）、低差异化（产品同质化严重）。在这种行业里，成本优势和地理布局是核心生存要素。赛轮的海外布局确实领先，但这不是不可复制的——三角轮胎、玲珑轮胎、森麒麟等同行也在加速出海。

FY2023：利润跃升的转折年

巴菲特：

FY2023是赛轮的关键转折年。归母净利润从13.32亿跃升至30.91亿（+132%），毛利率从18.42%跳升至27.64%。核心驱动：①越南工厂满产运营，贡献大量低成本产能；②柬埔寨工厂产能释放；③原材料价格回落。这验证了海外产能布局的战略价值。

芒格：

需要验证：FY2023的OCF为53.13亿，远高于归母净利润30.91亿（比值1.72），看起来非常健康。但FY2024 OCF骤降至22.89亿（比值0.56），而净利润却增至40.63亿。这种OCF与净利润的严重背离需要解释——最可能的原因是FY2024营运资金大幅占用（应收账款和存货随营收增长而膨胀），并非利润质量问题。FY2025 OCF回升至41.79亿（比值1.19），验证了这一判断。

FY2025：利润回调与扩张加速

巴菲特：

FY2025归母净利润35.22亿（-13.30%），主要受以下因素拖累：①天然橡胶等原材料成本上涨；②欧盟反倾销终裁影响出口；③新工厂（印尼、墨西哥）处于爬坡期，尚未盈利。但营收仍增长15.69%至367.92亿，说明销量增长对冲了价格压力。有息负债从104.95亿增至120.56亿，反映持续的资本开支。

芒格：

有息负债持续攀升：FY2021的82.88亿 → FY2025的120.56亿 → 2026H1的146.75亿，五年增长76.9%。净负债从34.47亿增至94.68亿，增长174.5%。公司用债务为海外扩张融资，这在当前低利率环境下可以接受，但必须关注：①这些新工厂何时能产生足够的回报来覆盖债务成本？②如果贸易环境恶化，海外工厂回报低于预期，债务负担将成为沉重压力。

2026H1：复苏确认

巴菲特：

2026H1是复苏期。营收200.27亿（+13.88%），归母21.60亿（+17.97%），毛利率回升至26.99%。关键数据：

  • 越南子公司：收入46.5亿，净利润8.2亿，净利率17.7%（稳定高产期）
  • 柬埔寨子公司：收入44.1亿（+40.4%），净利润9.5亿（+101%）
  • 两家海外子公司半年合计净利润17.7亿，占归母净利润的82%——海外产能是绝对利润核心
芒格：

海外子公司贡献了82%的利润——这是"关税套利"价值的直接量化。但也意味着公司对中国贸易政策的敏感度极高。存货周转率1.91次，应收账款74.23亿（占营收37%），这些营运资金指标需要持续监控——轮胎行业的应收账款风险不容忽视。OCF仅10.33亿（半年），远低于净利润21.60亿，现金转化率0.48——可能存在营运资金占用或资本支出前置。

长期盈利能力评估

巴菲特：

六年营收CAGR 19.0%，归母CAGR 18.8%——增长强劲。但利润增长极不均匀：FY2020-2022三年归母净利润在13-15亿之间停滞，FY2023-2024跳升至31-41亿，FY2025回落至35亿。这反映了两阶段特征：

  • FY2020-2022（布局期）：毛利率18-20%，国内产能为主，利润受原材料和需求波动
  • FY2023-2026H1（收获期）：毛利率跃升至25-28%，海外产能满产贡献利润，但原材料压力和贸易壁垒开始显现

六年毛利率中位数22.3%，但分两段看更合理：前三年中位数18.4%，后三年中位数26.1%。毛利率的台阶式提升是海外产能规模化+产品结构优化的结果，具有结构性。

芒格：

关键问题：后三年26%的毛利率是否可持续？橡胶和炭黑价格在2026年持续上涨（天然橡胶从$1,800涨至$2,300/吨），这是FY2025毛利率回落至24.68%的主因。如果原材料继续上涨，毛利率可能进一步承压。但海外工厂的低成本优势（自备电厂、廉价劳动力、关税豁免）提供了部分缓冲。综合判断，25-27%是中周期合理毛利率区间，但存在下行风险。

现金流与资本配置

巴菲特：

OCF波动极大（21.99至53.13亿），中位数约35亿。这与净利润的比值在0.56-1.72之间，说明营运资金变动对OCF影响巨大——轮胎行业的应收账款和存货随营收增长而膨胀。有息负债从~75亿增至146.75亿，六年增长近一倍，主要用于海外建厂。公司处于"用债务换产能、用产能换增长"的扩张周期。

巴菲特：

赛轮的核心护城河是"先发海外产能布局"带来的成本优势。越南和柬埔寨工厂已满产，净利率17.7%，远高于国内。墨西哥工厂直接服务北美市场，规避关税。这种优势的来源是"行动早"——2012年就进入越南，比大多数同行早5-8年。先发优势带来了更低的土地成本、更成熟的供应链和更稳定的客户关系。

芒格：

但这个护城河面临三个侵蚀威胁：①同行正在加速出海（三角32亿投柬埔寨、玲珑泰国/塞尔维亚、森麒麟摩洛哥），先发优势正在缩小；②美国可能对越南产轮胎也加征关税（"关税原产地穿透"风险）；③原材料价格波动可侵蚀成本优势。评级：窄护城河（Narrow Moat），来源=成本优势+先发布局，趋势中性偏负面（竞争者追赶中）。

Prompt 7: 保守估值与内在价值

执行级别：深度审查级

估值方法：高回报成长型 FCFF DCF

核心驱动：海外产能释放节奏、原材料价格周期、贸易政策环境。采用FCFF口径（企业视角），以NOPAT为起点。

基期正常化现金流

巴菲特：

三锚正常化检查：

  • 历史锚：FY2020-FY2025归母13.13-40.63亿，六年中位数~17.5亿，三年中位数35.2亿
